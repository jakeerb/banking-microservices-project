# Banking Microservices Project

Production-style banking microservices application built using Spring Boot, Kafka, Docker, MySQL, and GitHub Actions.

## Architecture

- API Gateway
- User Service
- Auth Service
- Card Service
- Transaction Service
- Fraud Detection Service
- Kafka
- MySQL

## Technologies

- Java 17
- Spring Boot
- Spring Cloud Gateway
- Spring Data JPA
- MySQL
- Apache Kafka
- Docker
- GitHub Actions
- Maven

## Services and Ports

| Service | Port |
|---|---:|
| API Gateway | 8080 |
| User Service | 8081 |
| Auth Service | 8082 |
| Card Service | 8083 |
| Transaction Service | 8084 |
| Fraud Detection Service | 8085 |

## Features

- User registration
- Authentication with JWT
- Card management
- Transaction processing
- Kafka event streaming
- Fraud detection
- Transaction status update
- Dockerized microservices
- CI/CD using GitHub Actions
